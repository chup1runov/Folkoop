# Сводка подтверждений организатору

18 октября 2026. Локальный код; проверки и публикация отложены пользователем.

В карточке встречи организатор видит три группы: подтвердили участие,
участники проекта без ответа, отозвавшие подтверждение. Ответы фильтруются строго
по версии текущих условий. Старое согласие не становится новым. «Ждём ответа»
не означает обещание участия; отдельного списка приглашённых в текущей модели нет.

Для ведущего и открывающего помещение показаны имя и причина нехватки:
нет предложенного человека; человек больше не член проекта; роль отозвана;
не подтверждено участие; не подтверждена роль. Роль считается закрытой только
при подтверждённом участии и принятой роли этой же версии.

Показано количество людей до минимального состава. Подтверждения участников
не подменяют согласование помещения: при отсутствии актуального согласования
есть отдельное предупреждение. Устаревший, офлайн или неактуальный снимок
не показывает сводку как действующие подтверждения.

Используются существующие данные карточки и серверного снимка; новых прав,
таблиц, рассылок и изменений данных нет. Черновые подписи добавлены для 11 языков,
человеческое одобрение переводов не заявляется.
