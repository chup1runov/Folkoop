# Следующий шаг проекта

23 октября 2026. Локальный код, не проверен и не опубликован.
Миграций и новых запросов к базе нет. Проверки не запускались по просьбе владельца.

Существующий renderOverview в network-decisions.js дополнен первым действием
и раскрываемым списком остальных вопросов. Ранний список «Требует внимания»
представлен теперь через этот блок; протокол, участники и задачи остаются ниже.
Приоритет: недоступные/старые данные → согласования основания задач и встречи →
результаты на проверке/доработка → остальные вопросы → рекомендация обсудить решение.
Это фиксированная навигационная эвристика, не оптимальный план и не новые права.

Кнопки переходят к существующим разделам задач, решений или встречи; раскрывают
родительские details и переносят фокус. Обновление использует существующее действие
refresh. Ни один переход не создаёт согласие, не назначает роль и не сдаёт результат.
Общий список доступен участникам, не персонализирован по праву выполнить действие:
кто вправе подтвердить/изменить запись, определяют прежние формы и сервер.

Закрытый проект показывает информационную подпись, не призыв исполнять задачи.
Без настроенной встречи не требуются помещение и роли. После времени окончания
предлагается просмотр результата встречи, а не сбор прежних согласий; это не
утверждение, что результат отсутствует. Отсутствие выявленных проблем не выдаётся
за готовность. Снимки старше минуты, офлайн и ошибки отделены от нехватки согласий.
Проверка свежести выполняется при отрисовке, автоматического таймера нет.

11 языков получили черновые строки без человеческой приёмки. Мура не изменена:
обзор по-прежнему только для настоящих участников; её отдельная история отложена.
Сводка самостоятельных согласий с документами остаётся в прежнем блоке документов;
новый маршрут учитывает их через основание конкретной задачи, не объявляет полную
проверку всех документов проекта. Полный список может быть длинным, но свёрнут.

Отложенная приёмка: свежие/старые/ошибочные данные, закрытый проект, проект без
встречи, прошедшая встреча, основания задач, два типа участников, раскрытие/фокус,
мобильная ширина/RTL, смена аккаунта и сохранность прежнего обзора.
