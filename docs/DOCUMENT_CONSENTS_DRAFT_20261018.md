# Личные согласия с версиями документов

18 октября 2026. Локальный непроверенный код. Миграция, проверки и публикация
не запускались по просьбе пользователя.

Для правил и смет участник подтверждает явно указанную редакцию от своего имени.
Создание/редактирование, просмотр и молчание не создают согласия. При новой версии
нет переноса ответов. История редакций показывает прежние ответы отдельно.
Отчёты этим механизмом не утверждаются. Подтверждение сметы не является оплатой,
разрешением списания денег, юридически значимой подписью или коллективным решением.

Статусы: подтверждено, нет ответа, отозвано. Это индивидуальные ответы, не кворум
и не общий флаг «утверждено». Бывшие участники отмечаются отдельно. Человек может
отозвать собственный ответ, в том числе на старую редакцию; подтвердить заново
можно только актуальную редакцию активного проекта. Повтор одинакового ответа
не меняет время. Хранится последнее состояние ответа на каждую версию, а не
полный журнал всех отзывов и повторных подтверждений внутри одной версии.

Сервер: активная сессия, членство, допустимый тип документа, текущая версия;
auth.uid() задаёт отвечающего, подменить участника параметром нельзя. Блокировка
проекта общая с сохранением документа. Прямые изменения таблицы запрещены.
RLS разрешает чтение участникам проекта. До 1000 ответов на проект; превышение
показывает недоступность вместо неполного списка. Пагинация ответов отложена.
Снимок старше минуты/офлайн не выдаёт ответы за актуальные; сервер всё равно
повторно проверяет версию при отправке.

Текст и связи создаются как новая редакция обычным сохранением. Техническое
обнуление связи при удалении решения не является новым утверждением документа;
документ не выступает юридическим неизменяемым архивом. Общего правила обязательных
подписантов/блокировки задач до утверждения пока нет.

Личная ограниченная выгрузка — 31 коллекция, включая свои доступные ответы.
Inventory v12 расширяет v11. Удаление аккаунта или версии удаляет связанные
ответы каскадно. Выход из проекта прекращает доступ, но не стирает исторический
ответ. При повторном вступлении ответ той же версии сохраняется; это не новый
акт согласия. Операторский экспорт нужен для записей вне текущих прав пользователя.

Отложено: два аккаунта; изменение одновременно с согласием; старый экран;
отзыв, повтор, выход/вступление; архивный проект; RLS/отзыв сессии; история;
экспорт/удаление; мобильный интерфейс, RTL и редактура 11 языков.
