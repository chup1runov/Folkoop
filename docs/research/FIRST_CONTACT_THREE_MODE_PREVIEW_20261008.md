## Content and routes

The preview presents three equally prominent choices, using the existing eleven-language production translations from `network-ui.js`:

- **Be among people** — read community/Center and City-linked opportunities; intentional navigation to `#/center`.
- **Solve one concrete question** — two explicit sub-actions for a **Need** or an **Offer**, creating only a *private local draft*, never auto-publishing a network cooperation.
- **Organise something together** — start with a *private local Project draft*, not a published project or an invitation sent to real participants.

Mura remains a secondary, explicit, read-only exploration route. This trial shows the product purpose without claiming a physical venue, a working human Host, internal payments, automated matching or verified participants. The regular account path is not altered.

The new headline and brief explanation have candidate translations for all eleven languages (SV/EN/AR/SO/FA/FI/BS/KU/ES/RU/UK), but **no independent fluent-reader approval is claimed**. Right-to-left controls use the current Arabic/Persian direction conventions; Kurmanji remains Latin-script LTR.
