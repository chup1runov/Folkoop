### PWA/release
Existing clients can remain stale even when fresh CI is correct. Release truth has three layers:
1. source/CI;
2. deployed public origin;
3. existing real-device client.

Service-worker updater uses forced update checks, waiting-worker activation and controllerchange reload protection.

Never call a change production-complete before public-origin production smoke passes.

### Security
Current main includes restrictive CSP/XSS hardening:
- script-src self only;
- no unsafe-inline scripts;
- no unsafe-eval;
- object-src none;
- base-uri none;
- controlled connect-src;
- browser injection regressions;
- explicit escaping regressions at network rendering boundaries.

frame-ancestors is not in meta CSP because browsers do not enforce it there. Add it as an HTTP response header only when hosting supports response-header control.
