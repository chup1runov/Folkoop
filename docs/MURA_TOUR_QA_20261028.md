## Исправления

1. В `network-ui.js/render` гостевой список разрешённых кнопок скрывал ответы
   и возвраты экскурсии. Добавлен отдельный узкий список безопасных действий
   истории; ограничения реальных записей сохранены.
2. В обработчике `folkoop:guest-demo` промежуточный hashchange на профиль мог
   сбросить восстановленную карточку. Для экскурсии маршрут теперь выбирает
   сам механизм восстановления, без промежуточной навигации.
3. Городские истории используют общую функцию `openSubsection`, а не клик по
   временной скрытой ссылке. Обратный переход транспорт → службы перепроверен.
4. Заголовки историй получили отступ при прокрутке под закреплённой шапкой.
5. Более специфичное правило flex гарантирует отдельную полную строку для
   навигации истории: текст больше не сжимается в узкую боковую колонку.
6. Панель помощника ограничена высотой экрана с прокруткой: раскрытая карта
   больше не вытесняет заголовок и кнопку закрытия выше экрана.
7. Цель подсветки главы «Вместе» исправлена с отсутствующего h1 на существующий h2.

Исходники: [folkoop.js](../apps/web/folkoop.js),
[network-ui.js](../apps/web/network-ui.js), [folkoop.css](../apps/web/folkoop.css).

## Границы результата

Не запускался весь тестовый набор; нет проверки реального устройства, других
браузерных движков, всех 11 языков или native review. Внешние расписания,
бронирования, цены и отправка обращений не проверялись. Пробные тексты и чекбоксы
по контракту остаются только на текущей странице; сохраняются позиция и открытия.
18/18 означает открытые истории, не доказанное прочтение или выполнение заданий.
Тексты отдельных старых карточек ещё требуют редакторского прохода; одинаковая
проба в «Вместе» и «Центре» остаётся UX-кандидатом на улучшение, не доказательством
интереса новых пользователей. Миграции, commit, push и публикация не выполнялись.
