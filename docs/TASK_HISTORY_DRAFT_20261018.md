# История в карточке задачи

18 октября 2026. Локальная непроверенная реализация. Тесты, сборка, запросы к
рабочей базе и публикация не запускались по просьбе владельца.

В новых задачах добавлен раскрываемый блок истории. Источник — существующая
`fk_task_work_events`: принятие, отказ, каждая сдача, возврат с причиной и
подтверждение с комментарием. Показываются участник, действие, время устройства
и сохранённое пояснение. Для недоступного профиля используется нейтральная подпись;
историческое имя не выдумывается и отдельно не архивируется.

Загрузка по кнопке, по 50 событий, новые сверху. Дополнительная 51-я строка
определяет наличие следующей страницы; курсор — ревизия, не смещение.
Кнопка «Обновить историю» начинает с последних событий. Ошибка показана отдельно,
не как утверждение об отсутствии истории. Состояние очищается при смене аккаунта;
после изменения ревизии задачи ранее загруженная история больше не отображается.
Текст экранируется. Доступ определяется прежними RLS и сессией.

Новых таблиц/миграций нет. История старых legacy-задач не реконструируется.
Удаление задачи по прежним правилам удаляет её события; это не неизменяемый архив.
Интерфейс переведён черновым образом на 11 языков, без языковой приёмки.

Отложенная приёмка: полный цикл из двух аккаунтов, повторная сдача, более 50/100
событий, одинаковое время разных ревизий, сбой загрузки, отзыв доступа, смена
аккаунта во время запроса, удалённый автор, XSS-текст, клавиатура и RTL.
