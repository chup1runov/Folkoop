Baseline commit: `09e29aad3cad3b9d3ee4403881e02ac4b9022073` (pre-FOLKOOP civic baseline v0.14.0).

FOLKOOP is one repository, one project and one product identity. Earlier civic and
community-center concepts were integrated as FOLKOOP City and FOLKOOP Center.
Historical Git commits/refs remain provenance records, not current product brands.

## Deliberate limitations

The integration did not fabricate message delivery, savings guarantees, users,
city case statuses, political scoring or checkout. Completion markers were not
treated as independent proof of real-world outcomes.

## Provenance and rollback

Pre-FOLKOOP baselines remain in Git history and archival refs. Rollback should
use normal Git commits/reverts; do not rewrite shared history merely to rename
past internal labels. User-facing and active-source naming is FOLKOOP.

## Brand provenance

The owner instructed reuse of the supplied master graphic mark for FOLKOOP.
`folkoop-mark.png` is a cropped/resized raster from that supplied master board,
not a claimed vector master. This history note is not a trademark-clearance
opinion.
