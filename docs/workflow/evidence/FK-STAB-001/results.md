## История результата (C02)
Forward-миграция `20261106180000_preserve_meeting_outcomes.sql` заменяет зависимость результата от членства прямым Auth FK. Исключение/выход не удаляют прошлую оценку и не снимают разногласие. Закрытие Auth-аккаунта по-прежнему удаляет его личные записи, удаление встречи — её результаты. Посторонние не получают доступ; тест проверяет также запрет прямого редактирования организатором.

## Сообщения (C03/C04)
Курсор `(created_at,id)`, сортировка desc на сервере и хронологический показ, lookahead 101 для страницы из 100, кнопка более ранних сообщений. Микросекунды не обрезаются. При открытии — последние сообщения; при дозагрузке — сохранение позиции и черновика. Смена аккаунта/чата отсекает устаревший ответ.
Прочтение — только ID сообщений, показанных viewport активной вкладки, без автоматического очищения при отправке. `fk_message_reads` доступна пользователю только для своих записей; RPC проверяет членство и принадлежность сообщений чату. Старый `fk_mark_chat_read` сохранён как безопасный no-op с проверкой доступа. Никакого вывода о том, что человек действительно прочёл/понял текст: это отметка показа, не доказательство внимания.
Новая таблица включена в ограниченный экспорт (43 секции) и накопительный closure inventory v20; удаление членства/аккаунта удаляет личные отметки прочтения. Старая временная отметка служит исторической границей: уже ошибочно прочитанные записи до исправления автоматически не восстанавливаются.

## Городские источники (C05)
`npm run build` теперь использует `build-production.mjs`: оба официальных fetch-скрипта → нормализованные JSON → валидация → сборка → аудит артефакта. GitHub использует ту же команду, что Cloudflare. Нет молчаливого пропуска `data`. Проверяются схема, домен источника, дата получения (до 24 часов), обязательные поля, размер списка; реальный пустой список консультаций допустим. Post-deploy smoke проверяет MIME/JSON, исключая HTML SPA fallback.
Офлайн QA доступна явно: `npm run build:shell` / `build-site.mjs --shell-only`, без городских лент; не production artifact. Полная production-цепочка прошла в изолированном тесте с явно синтетическими ответами официальных endpoints. Свежая попытка настоящего fetch завершилась ECONNRESET; build остановился, не выдав ложный успех. [Исходный вывод](live-build-failed.raw.txt). Настоящая свежая загрузка и опубликованные URL этим исправлением ещё не подтверждены.

## Почему менялись существующие тесты
Зафиксированные до работы 13 локальных падений не скрывались: export 20→43 и отдельная проверка соответствия коллекций ключам; разрешено происхождение названий только в `wiki/concept.md`; ожидаются принятые пять глав/18 историй вместо точных строк старой экскурсии; harness встреч загружает реальный Budget-модуль; API активности учитывает существующие новые секции; HTML sink проверяется с сохранением escaping после двух добавленных story-renderers. Observer теперь служит отметке видимости сообщений, запрет infinite scroll сохранён.
Два старых SQL-теста согласованы с моделью: историческая задача помечается legacy для проверки совместимости; чтение проверяет ID вместо now(). Browser fixture встречи обновлён с старого snapshot на актуальный ready_snapshot, не ослаблены согласия/отказы. Первый browser meeting упал на устаревшем endpoint fixture, после исправления прошёл.
