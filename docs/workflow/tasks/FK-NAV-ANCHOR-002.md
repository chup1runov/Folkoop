# FK-NAV-ANCHOR-002 — подпункты рядом с основной кнопкой

2026-11-09. Лёгкий режим для небольшого совместимого UI-изменения.
Baseline: e94ac8e; единственное старое untracked — data/, сохранено.
Копии исходных изменяемых файлов: /tmp/folkoop-nav-anchor-baseline-20261109.

Цель владельца: сократить путь пальца/мыши от основной кнопки к её подпунктам.
Критерии: компактные группы у родителя, «Контакты» над «Сообщениями», профиль
и настройки рядом слева; центр посередине; все прежние ссылки/подписи сохранены.
Минимум 44×44 CSS px, без выхода за экран, поддержка RTL, изменения размера и
трёх режимов навигации. Физическое расстояние в сантиметрах зависит от экрана.

Изменение: folkoop.js positionContextDock измеряет реальное положение родителя
и ограничивает группу краями основной линии; правые группы раскрываются влево
(зеркально в RTL). folkoop.css убирает растяжение подпунктов и ограничивает ширину.
Порядок DOM, маршруты и aria-label сохранены. Схема данных, права и БД не меняются.

Самопроверка плана/результата через folkoop-verify; не независимое ревью.
Node --check, 7 navigation-ia unit, static-smoke, shell build и diff --check прошли.
Временная проверка /tmp/folkoop-nav-anchor-check.py: Chromium/WebKit,
320×740, 390×844, 1366×900, 390×844 RTL и 844×390; 3 режима × 5 разделов;
геометрия, доступность центров кнопок, отсутствие overflow, переходы сообщений
и resize прошли. Выборочные скриншоты просмотрены: /tmp/folkoop-nav-anchor/.
Существующий tests/e2e/navigation-ia-browser.py на WebKit также прошёл.
Это браузерные размеры, не физический iPhone; новые переводы не добавлялись.

Публикация и текущий hosted CI: ожидаются. Ранее существовавший внешний сбой
GitHub Pages описан в FK-STORIES-004; его исправление этим CSS не утверждается.
Откат: только два изменённых участка CSS/JS, без удаления функций или данных.
