# Rights proposal — owner approval required

Status: proposal only, 23 September 2026. The adjacent RESTRICTED_TERMS_DRAFT.en.md is not an adopted licence. There is no new root LICENSE, no change to runtime files, visibility, hosting, history or existing agreements.

## Proposed decision

No general reuse permission. Normal intended resident use of the official website/PWA remains free. Separate copying, adaptations, non-commercial and commercial deployments, integration, distribution, sublicensing and use of protected branding need express written approval from Pavel, except where binding law, a platform agreement, an earlier grant or a third-party licence already permits the act.

## Approval gate

Before adopting the draft:
1. Review ownership and provenance of the code, assets and contributions, and inventory dependencies. The current package declares serve; the development dependency is not automatically owned by the maintainer. This proposal is not a complete dependency or rights audit.
2. Decide public versus private source hosting. Public GitHub viewing and platform forking cannot be removed by a repository notice. The standard platform agreement also has independent content-processing grants; determine the agreement actually applicable to the account.
3. Approve the precise text and effective date. Only then move an adopted version to LICENSE and reconcile README/CONTRIBUTING, preserving previous agreements and third-party notices.
4. Review legal text with a Swedish IP specialist before relying on it for commercial enforcement. No universal enforceability or automatic penalty is promised.

For greater control of future disclosure, private source hosting and a separate public build are candidates. Do not switch visibility without approval and a hosting/plan check. Existing public forks and copies do not disappear, and delivered browser JavaScript remains inspectable. A private repository is not a substitute for enforceable rights or server-side protection of confidential logic.

## Permission requests

Requests go to the maintainer-approved public address chup1runov@gmail.com. Identify the recipient, exact files/version, intended acts, commercial/non-commercial use, deployment/distribution, duration, territories, subcontractors and any requested transfer rights. Do not include secrets or private user records. The request itself is not permission; silence, an informal discussion or payment alone is not agreement. Separate agreements must explicitly settle scope, fees and termination if applicable.

The proposed contribution policy requires agreement on provenance and rights before accepting substantial third-party contributions. A pull request is not an automatic copyright assignment. This document does not alter existing contributor rights.
