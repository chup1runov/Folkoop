# Brand clearance — Sverinav

Status: **provisional brand / arbetsnamn**

Datum: 2026-09-21

## Styrkor

- Kort och lätt att uttala.
- Associerar till Sverige + nav utan att vara en exakt beskrivande fras.
- Fungerar för en nationell civic-tech-plattform.
- Ingen tydlig exakt etablerad produkt med namnet hittades i den preliminära offentliga sökningen.

## Risker

### NAV-association

Det finns:
- NAV Sweden,
- norska NAV.

Därför ska varumärket alltid skrivas som ett ord:

**Sverinav**

Inte:
- SveriNAV
- Sveri Nav
- Sverige NAV

## Innan offentlig lansering

Gör full manuell clearance:
1. PRV
2. EUIPO / TMview
3. WIPO Global Brand Database
4. Bolagsverket / verksamt
5. Internetstiftelsen för sverinav.se
6. .com / .app / .org
7. GitHub/social handles
8. professionell förväxlingsbedömning vid behov
