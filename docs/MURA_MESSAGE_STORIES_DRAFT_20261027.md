# Мура: истории сообщений и компактный интерфейс

27 октября 2026. Локальный непроверенный код; публикации нет.

В главе «Сообщения» три необязательные истории:
- личная переписка с Omar о получении дров;
- отдельная группа прогулки (не рабочий чат проекта);
- связанный чат проекта обмена растениями.

Выбор открывает существующий иллюстративный чат, снимая модальность.
Над перепиской компактная реплика с портретом Муры. «Попробовать ответ»
раскрывает редактируемый пример черновика (до 1000 символов), без отправки.
Текст остаётся только в DOM, исчезает при перерисовке/уходе и не попадает
в API, историю сообщений, localStorage или аналитику. Введённый текст
не воспринимается как реальная реплика Муры или сообщение участнику.
Возврат ведёт в главу; пробы не обязательны для завершения экскурсии.

Выбор ограничен guestDemo: личный direct, group без связи с проектом,
либо чат фиксированного проекта из demoSnapshot. Внешние ID не принимаются.
Прежние ограничения демонстрационных сообщений сохранены.
Прогресс сохраняет главу, а не выбранный чат и пробный текст.

Область compact-messenger делает список чатов строками с разделителями,
уменьшает отступы и тени сообщений, ограничивает превью двумя строками.
Применяется к разделу сообщений обоих режимов; функции реального общения
не меняются. Кнопка открытия сохраняет минимум 44×44 CSS px.
Это собственная компактная компоновка, не копия Telegram.

Источники: запрос владельца 27 октября; apps/web/network-ui.js —
muraMessagePractice и folkoop:mura-message-open; apps/web/folkoop.js —
muraMessageStories и возврат; apps/web/folkoop.css — compact-messenger.
Строки для 11 языков — черновые, без человеческой вычитки.

Не запускались тесты, линтер, сборка, браузер, проверка ссылок и локализации.
Отложены проверка переноса/RTL, клавиатуры, фокуса, выбора трёх разных чатов,
возврата, смены аккаунта и отсутствие отправки пробного текста.
Нет миграций, commit/push и публикации.
