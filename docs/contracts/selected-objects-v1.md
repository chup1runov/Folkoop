# Selected objects v1 — добровольный обмен

Статус 2026-11-09: локальный формат для совместного испытания; внешней интеграции нет. [Схема](selected-objects-v1.schema.json), [синтетический пример](selected-objects-v1.example.json), [исполняемый валидатор](../../apps/web/network-exchange.js).

В профиле участник выбирает 1–20 собственных открытых потребностей, предложений или ресурсов, явно указывает сведения, проверяет пакет и скачивает его отдельным нажатием. Смена аккаунта очищает черновики. Снимок старше минуты или сменившаяся загрузка требует подготовки заново. Экспорт касается только загруженных доступных записей, не полного каталога.

- `id`, `type`, `title`: выбранный объект. `source.object_id` совпадает с `id`; `updated_at` — время изменения исходного объекта или null, `observed_at` — время чтения. Это временные метки, не криптографическая подпись или номер транзакции.
- `quantity`: null, если неизвестно; иначе десятичная строка `value` (до трёх знаков, 0 < значение <= 1e9) и непустая единица `unit`. Строка сохраняет точность, например `1.250 kg`; пересчёта единиц нет. Вместимость и доступный остаток не выводятся автоматически.
- `period`: null либо пара канонических UTC-времён `from` / `until`, конец строго позже начала. Форма использует часовой пояс устройства.
- `place`: `unspecified` с пустой строкой либо явно написанный район/город `area`. Исходный адрес не копируется. Точность введённого человеком текста программно не удостоверяется.
- `conditions`: явно введённые условия. Пустая строка означает отсутствие переданных условий, а не отсутствие ограничений.
- `source.declaration=exporter_statement`: сведения заявил составитель. Название и ID взяты из выбранной записи; количество, сроки, район и условия введены для этого пакета. Это не бронь, согласие получателя или доказательство права распоряжаться ресурсом.

Не включаются owner/user IDs, профили, контакты, переписка, описание объекта, чужие возражения, документы, согласия, история выдачи и учётные данные. Свободный текст пользователь проверяет перед передачей; автоматического обезличивания не заявляем.

JSON Schema задаёт структуру; `FolkoopExchange.validate` дополнительно проверяет семантику: совпадение ID, дубли, порядок дат, канонические даты, численные границы и непустые после trim строки. Все неизвестные поля и версии отвергаются. `parse` ограничивает текст 200000 кодовыми единицами JS. Вложенные файлы, ссылки для загрузки и исполняемые команды не поддерживаются.

Обратное чтение: вставить JSON в форму проверки. Она вызывает только parse/validate и безопасное отображение текста. Нет сетевых запросов, автоматической записи, объединения объектов или принятия чужих условий. Успешная проверка подтверждает формат, а не происхождение/правдивость. Экспорт не отправляет файл кому-либо.
