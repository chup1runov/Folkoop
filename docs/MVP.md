# MVP v0.2

> **Superseded product-scope document.** This describes the earlier civic MVP. It is retained for provenance. Current product scope is defined by `PRODUCT_CONCEPT.md`; current pilot scope by `GOTEBORG_CORE_LOOP_PILOT.md`; current execution by `WORK_PLAN_20261001.md`.


## 1. Vem ansvarar?

Input:
- vanlig text,
- plats,
- senare foto.

Output:
- sannolik ansvarig aktör,
- varför,
- officiell kontaktväg,
- källa.

## 2. Rapportera

Flöde:
1. Vad har hänt?
2. Var?
3. Foto, valfritt.
4. Vem ansvarar?
5. Förhandsgranska.
6. Skicka vidare via officiellt API/formulär/länk där integration tillåts.
7. Spara eventuell ärendereferens.

## 3. Nära mig

Första pilot: Göteborg.

Datatyper:
- vägarbeten,
- trafikstörningar,
- detaljplaner och samråd,
- luftkvalitet,
- vattennivåer,
- annan relevant öppen data.

## 4. Beslut

- kort sammanfattning,
- vem som fattat beslutet,
- datum,
- geografiskt område,
- originalkälla,
- tydlig skillnad mellan fakta och kommentar.

## Inte i första MVP

- BankID,
- medlemsregister,
- politisk profilering,
- automatiska myndighetsbeslut,
- vårddiagnostik,
- fullständig nationell täckning.
