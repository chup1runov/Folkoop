# Уведомления о работе — локальный черновик

18 октября 2026. Код добавлен, **проверки не запускались**, миграция и публикация
отложены по просьбе владельца. Зависит от двух предыдущих черновиков:
[решения](PROJECT_DECISIONS_DRAFT_20261018.md), [работа с задачами](TASK_WORK_DRAFT_20261018.md).

## Реализация

- Принятие, освобождение, сдача, возврат и подтверждение задачи создают запись
  в существующей ленте проекта: автор + действие + название задачи.
- Событие появляется из `fk_task_work_events` в той же транзакции. Ошибка или
  повтор со старой ревизией не создаёт ещё одно уведомление.
- Общие `task_updated` подавлены для переходов нового цикла, чтобы не дублировать
  специализированное событие. Создание, удаление, legacy-задачи и предложения
  исполнителя продолжают использовать старую ленту.
- Существующие счётчики непрочитанного показывают события других участников.
  Проектная лента доступна участникам, не всему публичному каталогу.
- «Нужно твоё действие» находится в уведомлениях профиля и обновлениях проектов.
  Организатор видит ожидающие проверки результаты. Для работы организатора
  запрос видят другие участники. Исполнитель видит возвраты на доработку.
- Очередь выведена из текущего состояния задачи, не из флага прочтения.
  Она исчезает после нужного перехода, а не после открытия уведомления.
- Кнопка в очереди открывает проект, раскрывает задачи и переводит фокус к задаче.
  После удаления задачи или потери доступа нельзя обещать переход к старой карточке.
- Возвращаются первые 100 ожидающих задач с общим количеством. Ошибка загрузки
  не изображается пустым списком. Есть кнопка обновления.

## Границы

Только уведомления внутри приложения. Нет email, push, фонового опроса, обещаний
мгновенной доставки или внешних расходов. Список обновляется при штатной загрузке,
после действий и вручную. Проектные сводки по-прежнему показывают последнее событие;
остальные события доступны в истории проекта. Очередь действий отдельно от
счётчика непрочитанного, чтобы не складывать две разные величины.

Тексты результата/причины доработки не копируются в ленту. Названия задач могут
содержать личные сведения: при закрытии аккаунта действует прежняя проверка
свободного текста ленты. Новых персональных таблиц нет; inventory v5 сохраняется.
События отражают сообщения участников, не независимое доказательство результата.

Для 11 языков добавлены черновые формулировки. Языковая приёмка не проводилась.
Иллюстративная история Муры о карточках остаётся связанной с этим сценарием;
отдельная интерактивная демонстрация очереди уведомлений пока не добавлена.

## Отложенные сценарии приёмки

1. Один claim/submit/changes/approve → одно специализированное событие, без дубля.
2. Параллельные действия, отказ транзакции, повтор запроса — без ложного уведомления.
3. Организатор и исполнитель получают правильную очередь; самопроверки нет.
4. Открытие проекта гасит непрочитанное, но не убирает ожидающую проверку.
5. Возврат и новая сдача меняют очередь; подтверждение убирает ожидание.
6. Выход из проекта/отзыв сессии/закрытие проекта прекращают доступ к очереди.
7. Более 100 задач, сбой API, удалённая задача, смена аккаунта, клавиатурный фокус.
8. Legacy-лента, счётчики, 11 языков/RTL, Мура и приватность.

Не применять миграции и не публиковать этот код до отдельного этапа проверок.
