# Завершение знакомства с Мурой

28 октября 2026. Локально написано, не проверено и не опубликовано.

После последней обзорной главы, либо по кнопке «Завершить знакомство»
когда открыты все истории, появляется компактный диалог с портретом Муры
и короткой благодарностью за визит. Самостоятельную пробу он автоматически
не прерывает. Обзор глав можно закончить с пропусками: пропущенные истории
не становятся открытыми, текст финала не утверждает выполнение всех заданий.

«Остаться у Муры» закрывает диалог, оставляя текущую страницу аккаунта.
Escape также закрывает нативный dialog. «Повторить историю» раскрывает все
18 историй по пяти главам. Выбор закрывает финал и открывает выбранную историю
через существующий openMappedStory. Нет перехода к регистрации или настоящих записей.
Даже после временного знакомства из собственного аккаунта выбор финала сохраняет
режим Муры в текущей сессии; явный выход остаётся отдельным действием.

Карта открытых историй сохранена. Завершение означает окончание рассказа,
не успешное выполнение упражнений. Пробные тексты не сохраняются.
Новых ключей хранения нет, используются прежние состояние экскурсии/режим входа.
Строки на 11 языках — черновые, без человеческой вычитки.

Код: apps/web/folkoop.js — showTourFinale, tourFinaleCopy, nextStoryMarkup,
openMappedStory и обработчики завершения; apps/web/folkoop.css — mura-tour-finale.
