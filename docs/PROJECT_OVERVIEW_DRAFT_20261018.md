# Обзор проекта и протокол решения

18 октября 2026. Локальный код; проверки и публикация отложены пользователем.

В начале карточки реального проекта для его участников добавлен обзор существующих
данных: цель из описания, ответы на текущую встречу, принятые роли, помещение,
вопросы внимания, протоколы предложений/решений и задачи с исполнителями/статусами.
Новые согласия и дублирующие записи не создаются, права доступа не расширяются.

Протокол раскрывает вопрос, цель, варианты, индивидуальные ответы и пояснения;
для принятого решения — выбранный вариант, обоснование, автора, дату и связанные
задачи. Ответы консультативные, не юридическое голосование и не обязательство
выполнить работу. Это представление текущих записей, не новый неизменяемый архив.

Внимание: нет решения, предложения ждут ответа/фиксации, задачи без исполнителя,
результат на проверке, доработка, недостаточный состав, непринятые роли,
несогласованное помещение, ошибки/неактуальность снимка. Не всё перечисленное
является запретом продолжать работу. Отсутствие найденных препятствий не означает
готовность в реальном мире. Обычный проект без настроенной встречи не считается
заблокированным только из-за отсутствия помещения.

Снимок старше минуты или офлайн не выдаётся за текущие подтверждения. Сам обзор
не вводит дополнительный polling. Подробные формы ниже остаются местом действий.
Мура не получает реальные данные и новые сетевые операции; отдельная иллюстрация
обзора пока не добавлена. Старые задачи показывают свой прежний статус, не получают
автоматически статус проверенного результата. Подписи 11 языков — черновые.

Отложено: unit/browser проверки, перечень задач после принятия решения, отзыв
согласий, перепривязка помещения, проекты без встречи, ошибки загрузки, мобильный
интерфейс/RTL, история удалённых задач и отдельная иллюстративная история Муры.
