# Kärnflöden v0.2

## A. Hål i vägen

1. Användaren anger eller fångar plats.
2. Sverinav hittar närmaste vägsegment.
3. NVDB Väghållare avgör ansvar.
4. Kommunal väg i Göteborg → Göteborgs officiella Felanmälan.
5. Statlig väg → Trafikverket.
6. Enskild väg → förklara ansvar och identifiera nästa kontakt.

**Värde:** användaren behöver inte veta vem som äger vägen.

## B. Nära mig

Normalisera alla källor till:
- kategori,
- rubrik,
- position,
- start/slut,
- ansvarig,
- originalkälla.

Varje kort visar:
- Vad händer?
- När?
- Vem ansvarar?
- Källa
- Läs original / Påverka

## C. Förstå ett beslut

1. Hämta dokument via Riksdagens API.
2. Spara originalmetadata.
3. Skapa enkel sammanfattning.
4. Visa alltid dokumenttyp, datum, organ och originalkälla.
5. AI-sammanfattningar ska märkas som AI-genererade.

## D. Påverka lokalt

1. Importera öppna Göteborgsförslag.
2. Filtrera geografiskt eller efter ämne.
3. Visa röster, deadline och status.
4. Rösta/kommentera leder till Göteborgs officiella tjänst.
