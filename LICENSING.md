## GitHub compatibility takes priority

GitHub and its users retain all rights that the applicable platform agreement grants, not merely the visible Fork button. No charge, prior approval or extra condition applies to those rights under this notice. They include viewing and platform-authorised use/display/performance/reproduction, and GitHub's own applicable processing rights. The actual agreement sets the scope: this document neither expands nor cancels it. A fork does not automatically create an unrestricted outside-the-platform reuse licence.

No repository visibility, Pages, Actions, account permissions, API access, platform controls or Git history are changed by this adoption. A public repository cannot be made technically uncopyable by putting a notice in it. `private: true` in package.json only prevents accidental npm publishing; it is not GitHub repository visibility. GitHub may display a custom licence as unrecognised/Other rather than an OSI licence.

The Rights Holder and his expressly authorised agents can continue development within their existing authority. The owner's instructions authorising project work are not a general licence to unrelated parties. A repository-level notice does not change GitHub account settings or opt-outs; it cannot override GitHub's contractual content-processing rights.

## Asking for additional permission

Email **chup1runov@gmail.com** with:

1. Recipient/person or legal entity and a contact.
2. Exact files, assets and commit/version concerned.
3. Requested acts: copying, modification, testing, hosting, integration, distribution or branding.
4. Purpose, commercial/non-commercial status, users, location of deployment/distribution and duration.
5. Any contractors, onward sharing, transfer or sublicensing needed.

Do not include passwords, personnummer, exact home locations or confidential user cases. A request, acknowledgement, star, payment, feature discussion or generic review is not approval. Pavel's express written grant must settle the permitted scope. Any change beyond that scope requires fresh approval. Agreements should address fees, provenance, responsibility and termination explicitly; this notice supplies no automatic contract or fine.

No individual permission has been issued merely by adopting these documents. Keep private permission agreements outside the public repository.
