# Contributing to Sverinav

Tack för att du vill bidra.

## Rättigheter och godkännande först

Projektets kod är offentligt synlig men inte fritt licensierad. Läs `LICENSE` och `LICENSING.md`. Användning som kräver Pavel Chuprunovs tillstånd kräver ett uttryckligt skriftligt godkännande i förväg. Detta villkor inskränker inte rättigheter enligt GitHubs tillämpliga avtal, tvingande lag eller befintliga tredjepartslicenser. En GitHub-fork eller laglig granskning som redan är tillåten genom sådana rättigheter kräver inget extra tillstånd enligt projektets villkor.

Frågor och felrapporter kan lämnas via de befintliga kanalerna utan att bifoga hemligheter. Innan ett väsentligt externt kod-, text- eller bildbidrag införlivas ska projektägaren och bidragsgivaren komma överens om ursprung, rättigheter, distribution och eventuell vidarelicensiering. Ett PR innebär inte automatiskt överlåtelse av alla rättigheter. GitHubs gällande bidragsvillkor och eventuella separata avtal gäller fortfarande. Ett särskilt bidragsavtal kan behövas.

Projektägaren godkänner införlivande och nya användningstillstånd. Ingen generell rätt att återanvända eller driva en egen version uppstår genom en diskussion, stjärna, betalning eller teknisk granskning. Behåll alla tillämpliga tredjepartslicenser och upphovsrättsmeddelanden. Samla inte in underskrifter, avtal eller personliga uppgifter i ett offentligt PR.

## Grundprinciper

Bidrag ska stödja Sverinavs mål: ett enkelt, neutralt och källspårbart gränssnitt till det offentliga Sverige.

- Använd officiella eller tydligt dokumenterade källor för samhällsfakta.
- Behåll länken till originalkällan.
- Blanda inte sakinformation med partipolitiska budskap.
- Samla inte in fler personuppgifter än funktionen kräver.
- Lägg aldrig API-nycklar, tokens, personnummer eller andra hemligheter i repositoryt.

## Innan en pull request införlivas

Beskriv:
1. vilket problem ändringen löser,
2. vilken datakälla eller funktion som påverkas,
3. hur ändringen kan testas,
4. eventuella privacy- eller tillgänglighetskonsekvenser,
5. ursprung och rättigheter till tillagt material samt det överenskomna tillståndets omfattning.

Projektet är fortfarande i en tidig pilotfas och arkitekturen kan förändras.
