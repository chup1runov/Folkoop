# Contributing to Sverinav

Tack för att du vill bidra.

## Grundprinciper

Bidrag ska stödja Sverinavs mål: ett enkelt, neutralt och källspårbart gränssnitt till det offentliga Sverige.

- Använd officiella eller tydligt dokumenterade källor för samhällsfakta.
- Behåll länken till originalkällan.
- Blanda inte sakinformation med partipolitiska budskap.
- Samla inte in fler personuppgifter än funktionen kräver.
- Lägg aldrig API-nycklar, tokens, personnummer eller andra hemligheter i repositoryt.

## Innan en pull request

Beskriv:
1. vilket problem ändringen löser,
2. vilken datakälla eller funktion som påverkas,
3. hur ändringen kan testas,
4. eventuella privacy- eller tillgänglighetskonsekvenser.

Projektet är fortfarande i en tidig pilotfas och arkitekturen kan förändras.
