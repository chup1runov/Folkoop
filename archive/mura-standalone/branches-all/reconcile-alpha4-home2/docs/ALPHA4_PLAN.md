# Alpha 4 — Character Presence Restoration

This milestone restores the flagship Ksyusha art library and reconnects visual character presence to the already-hardened Mura runtime.

- richer Ksyusha action and attention assets;
- attention keyframes mapped to the 16-sector attention engine;
- explicit run → jump → land locomotion when perching;
- Home as the second world for relationship/history/privacy/surfaces;
- `Cmd/Ctrl + Shift + H` to open Home;
- no regression of the opt-in window-geometry privacy boundary.
